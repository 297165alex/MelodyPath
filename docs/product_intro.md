# 产品介绍

> MelodyPath是《程序设计训练（Rust语言）》AI Agent课程项目，同时将阶段性成果用于智理杯智能体大赛。

## 产品介绍（500 字以内）

音乐平台常把用户困在“越听越像”的推荐回音室里；不同平台的好友也很难分享一份双方都真正愿意听的歌单。MelodyPath 将歌单统一为标准曲目数据，用可解释的音乐路径替代黑盒列表：个人场景把推荐分为舒适区、拓展区与惊喜区，并说明每首歌连接了哪些已有偏好、拓展了什么音乐元素；好友场景计算共同与互补偏好，生成从共同入口到各自特色、Genre 变化平滑的桥梁歌单。离线 Demo 可稳定展示 Korean R&B 到 Neo Soul 的探索和跨平台好友比较。结果可经歌曲选择、平台匹配、版本确认后导出文件；配置 Spotify OAuth 后，还可在明确授权和二次确认之后创建新的真实歌单。

产品入口优先让用户通过平台官方授权连接账号，其次是粘贴公开分享链接；直接粘贴歌曲清单和文件上传只在接口不可用时作为备用。任何平台登录都发生在官方页面，MelodyPath 不接收平台密码、验证码或 Cookie。平台能力由 Rust 后端接口返回，链接识别、页面可访问、曲目读取与写回分别展示，不把其中一步冒充为完整接通。

## 技术与应用（300 字以内）

核心后端使用 Rust、Axum、Tokio、Reqwest、Serde 与 SQLx/SQLite。解析、标准化、统计、相似度、约束检查、排序、任务历史和费用计算采用确定性 Rust 逻辑；Agent Loop 负责选择工具、检查数据、调整候选并保存结果，通过 SSE 实时展示步骤且支持中断。前端采用 React、TypeScript 与 Vite。统一 Provider/Writer 适配器隔离平台差异；模型 Endpoint、参数、Token 价格与预算可配置，密钥仅来自环境变量。

## 创新与优势（300 字以内）

创新点一是“可解释的 Genre 路径”：推荐不止给答案，还展示从熟悉音色、律动与情绪到新风格的过渡依据。二是“跨平台双人桥梁”：不仅计算相似度，更优化双方覆盖、连续歌手限制和风格平滑度。三是“可信写回”：ISRC 优先、版本识别、地区可播检查、置信度分级与人工确认共同避免写错歌曲；没有真实平台能力时明确降级为文件或 Demo，不伪装成功。离线可用与真实集成解耦，既适合比赛稳定演示，也便于课程持续扩展。
