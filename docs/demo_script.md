# MelodyPath 3—5 分钟中文演示脚本

> MelodyPath是《程序设计训练（Rust语言）》AI Agent课程项目，同时将阶段性成果用于智理杯智能体大赛。

## 0:00—0:30｜问题与定位（首页）

“音乐推荐越来越懂我们，却也越来越像我们已经听过的歌。好友分散在不同平台，更难得到一份双方都愿意听的共同歌单。MelodyPath 是一个用 Rust 构建的可解释音乐探索 Agent：它不只告诉你听什么，还解释怎样从熟悉走向未知。”

镜头：向下滚动到“连接你的音乐平台”，指出所有能力状态来自后端；Spotify 使用官方授权，其他平台诚实显示配置、审核或未接通状态。再展示公开链接检查与折叠的备用导入方式，强调页面没有平台密码输入框。

镜头：扫过首页 Genre 路线图，指出“核心 Rust、无 Key 可运行、真实写入前确认”。

## 0:30—1:10｜个人品味地图（品味地图页）

“比赛演示使用明确标注的离线数据。用户 A 偏好 Korean R&B、K-pop 与 City Pop，能量集中在低到中等。这里的 Genre 多样性、歌手集中度、年代和能量由 Rust 确定性计算；系统描述的是歌单的音乐倾向，不推断年龄，也不诊断心理状态。”

镜头：点击 Demo；展示指标、Genre 柱状图、核心区/相邻区/空白区和数据限制。

## 1:10—2:00｜可解释探索（探索推荐页）

“Agent 不是返回一串歌名。它把路线拆成 Korean R&B、Alternative R&B、Neo Soul 三步；舒适区守住接受度，拓展区引入复杂和声与真实乐器，惊喜区再进入 Jazz-Funk 和更实验的制作。每首歌都有连接依据、拓展方向、匹配分与新颖性。”

镜头：沿路线移动，展开一张推荐卡，展示连接依据与分数。

## 2:00—2:45｜好友桥梁（好友桥梁页）

“用户 B 偏爱 Indie Rock、Britpop 与更高能量。两人直接相似度只有 46%，但互补度达到 81%。Agent 从共同的梦幻旋律出发，用 Funk 贝斯和另类电子制作做中间桥，再分别进入 Alternative R&B 与 Alternative Rock。每首关键歌解释它在桥上的作用。”

镜头：展示 A/B 卡、兼容指标、桥梁列表和 phase。

## 2:45—3:30｜可信的一键写回（推荐页导出弹窗）

“选择十首歌后，用户可以保存到 Spotify，或先导出真实 CSV、JSON、M3U8 文件。写回不是一个危险的立即按钮：先选择歌曲，再搜索匹配；ISRC 优先，否则比较标准化歌名、歌手、专辑、时长和版本。中置信度必须选择版本，低置信度不会写入。只有勾选明确确认后，Agent 才会创建新歌单。”

镜头：点击“导出歌曲清单”；全选、预览、确认、下载。随后快速打开 Demo 写入，指出 `DEMO` 标识和 `demo://` 链接不是平台成功。

## 3:30—4:20｜课程 Agent 能力（Agent 运行与历史页）

“这不是只有前端效果的原型。选择个人探索或好友桥梁后，Rust Agent 按工具步骤运行，通过 SSE 实时推送进度；现在中断一次，可以看到任务立即进入 cancelled。再次运行完成后，结果、步骤、Token 和费用保存在 SQLite。离线 Demo 没调用 LLM，所以用量如实为零。”

镜头：启动任务、展示进度、可选中断；打开历史查看保存结果。

## 4:20—4:45｜配置与结尾（设置页）

“模型 Endpoint、名称、温度、Token、超时、重试、单价和费用上限都可配置；Key 只来自环境变量。MelodyPath 用可解释路径拓展个人边界，用桥梁歌单连接不同的人，也用清晰授权与诚实降级守住用户信任。”
