# 中国音乐平台官方接口审计

更新时间：2026-09-05

## 结论

本轮没有新增中国平台连接器。当前项目未找到并验证可供普通个人 Web 应用直接使用、同时覆盖用户授权、个人歌单分页读取和歌单写入的通用官方接口，因此不得显示虚假的 Connect，也不得使用账号密码、Cookie、抓包接口、逆向客户端或模拟登录。

| 平台 | 当前状态 | 产品入口 | 原因 |
|---|---|---|---|
| 网易云音乐 | `IMPORT_ONLY` | 粘贴歌曲清单 / 文件 | 官方开发者中心需要正式申请；本项目没有获批并验收个人歌单 reader/writer。公开分享页只能识别和检查可访问性，不能当稳定 API 抽取曲目。 |
| QQ音乐 | `IMPORT_ONLY` | 粘贴歌曲清单 / 文件 | 已核对的腾讯官方资料属于受限 SDK/合作场景，不能据此宣称通用个人歌单 OAuth。 |
| 酷狗音乐 | `PARTNERSHIP_REQUIRED` / `IMPORT_ONLY` | 粘贴歌曲清单 / 文件 | 开放平台存在不等于本项目拥有个人歌单 OAuth 与 writer；获得正式资质前不显示 Connect。 |
| 酷我音乐 | `IMPORT_ONLY` | 粘贴歌曲清单 / 文件 | 尚未验证通用官方个人歌单接口。 |

## 公开链接边界

`PlatformService` 只允许已知官方域名、限制重定向与响应前缀大小，并拒绝本机/任意主机以避免 SSRF。识别出的链接可以显示平台与歌单 ID；“页面可访问”不等于“曲目可合法读取”。站点内部状态或不稳定页面结构不会被当作开放 API。

## 官方入口

- [网易云音乐开发者中心](https://developer.music.163.com/)
- [腾讯连连 QQ音乐 H5 SDK 文档](https://cloud.tencent.com/document/product/1081/67456)
- [酷狗开放平台文档](https://open.kugou.com/docs)

后续只有在拿到正式文档、应用资格、明确用途许可和真实账号验收后，才可改变能力矩阵。Mock、第三方逆向库或公开页面 HTML 成功解析都不能升级为 `CONNECT`。
